# 🚗 台灣汽車筆試題庫 2026 最新版 - 互動模擬測驗與刷題系統

收錄 115 年最新交通部公路局公告之 **1,090 題汽車筆試考題**（含 208 張標誌標線與情境圖示），提供全真模擬測驗、順序刷題、錯題本複習與關鍵字搜尋功能。

## ✨ 核心功能特色

* 🚀 **全真模擬測驗 (40 題 / 30 分鐘)**：按公路局比例隨機抽題，倒數計時與及格 (≥85分) 判定。
* 📚 **三大考題架構分類**：
  * **架構一**：正確觀念與態度（424 題，含酒駕毒駕處罰、危險駕駛、平交道、強制險）
  * **架構二**：主動停讓文化（230 題，含無號誌路口停讓、行人路權、兩段式開車門、大型車內輪差）
  * **架構三**：安全駕駛能力（436 題，含安全車距、頭燈霧燈使用、貨物超載、國道二次事故、車輛檢查）
* ❤️ **錯題本與星號收藏 (LocalStorage 持久化)**：自動記錄錯題並支援「錯題專屬重測」。
* 🔍 **全文與題號搜尋**：支援輸入關鍵字（如：酒駕、標線、180000、或題號 101）即時檢索。
* 🎨 **深淺色主題切換**：高質感 Glassmorphic 玻璃擬物風格與微動畫反饋。
